# Real Is Rare Apparel

## Custom E-Commerce Experience

Real Is Rare Apparel is an e-commerce project built around a clothing brand, with the focus on customising the online shopping experience rather than relying entirely on a default store theme.

### Technology

- Shopify
- Liquid
- HTML/CSS
- JavaScript

### Focus

- Custom storefront presentation
- Brand-focused e-commerce design
- Shopify theme development
- Product-focused user experience
- Adaptation of a commerce platform to a specific business

### Business perspective

An independent clothing brand needs more than a technically functional store. The storefront needs to communicate the brand, present products clearly and create a frictionless path from discovery to purchase.

This project explores the intersection between **software development, e-commerce and business requirements**.

## Why this project matters

This project demonstrates that I can work within an established platform such as Shopify while still using development skills to customise the experience for a specific business.
